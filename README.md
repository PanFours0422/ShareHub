# ShareHub

资源共享平台 — 一个基于 SpringMVC + MyBatis 的文件共享系统，支持用户注册登录、文件上传下载、分页查询、Redis缓存、验证码登录等功能。

---

## 项目简介

ShareHub 是一个用于资源共享的 Java Web 项目，旨在提供一个安全、高效、易用的文件上传与下载平台。项目集成了以下核心功能：

- 用户注册与登录（带验证码验证，保证安全性）
- 文件上传与下载管理
- 分页查看文件列表，支持AJAX动态加载
- 用户信息增删改查
- Redis缓存加速，提高访问性能
- 采用 session/cookie 进行会话管理
- 使用过滤器（Filter）实现统一拦截与权限控制

---

## 技术栈

- SpringMVC（Web框架）
- MyBatis（持久层框架）
- 数据库连接池：DBCP 或 C3P0
- Redis（缓存）
- Maven（项目管理和构建）
- AJAX（前端异步交互）
- Servlet Filter（请求拦截器）
- 验证码实现登录验证
- 文件上传和下载功能
